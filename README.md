# Churn Predictor
A personal project focused on deploying a Random Forest Classifier via a Flask web interface.

## About
I built this to experiment with how machine learning models move from a notebook environment to a live web application. It handles user input via a web form and returns a real-time prediction based on a pre-trained model.

## Tech Stack
* *Backend:* Python / Flask
* *Machine Learning:* Scikit-Learn / joblib
* *Frontend:* HTML/CSS

## How to Run Locally
1. Clone the repository.
2. Install dependencies: pip install -r requirements.txt
3. Run the app: python app.py
